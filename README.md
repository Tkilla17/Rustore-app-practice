# ShowcaseApp

Учебное Android-приложение с каталогом мобильных приложений в стиле витрины RuStore. Проект демонстрирует навигацию между экранами, загрузку данных через репозиторий и Retrofit, поиск, фильтрацию по категориям и обработку состояний интерфейса.

Данные приходят из локального mock API: Retrofit обращается к endpoint-ам, а `MockBackendInterceptor` возвращает подготовленные JSON-ответы без внешнего сервера.

## Возможности приложения

- Первый запуск открывает onboarding-экран с логотипом и кнопкой перехода в каталог.
- Основная витрина показывает список приложений с иконкой, названием, категорией и кратким описанием.
- Экран категорий отображает количество приложений в каждой категории.
- При выборе категории открывается витрина с отфильтрованным списком.
- Поиск вынесен на отдельный экран, поле ввода получает фокус автоматически.
- Поиск работает интерактивно по названиям приложений.
- Если совпадений нет, показывается подборка популярных приложений.
- Карточка приложения содержит разработчика, категорию, возрастной рейтинг, описание и скриншоты.
- Скриншоты открываются в полноэкранном просмотрщике и переключаются горизонтальными свайпами.
- На основных экранах есть pull-to-refresh, загрузка и экран ошибки.

## Используемый стек

| Область | Технологии |
| --- | --- |
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3 |
| Архитектура UI | ViewModel, UiState, MVI-подход |
| Навигация | Navigation Compose |
| DI | Dagger Hilt, KSP |
| Асинхронность | Kotlin Coroutines |
| Сетевой слой | Retrofit, OkHttp, Gson converter |
| Данные | Локальный mock backend через OkHttp interceptor |

## Как запустить

1. Открыть проект в Android Studio.
2. Дождаться Gradle Sync.
3. Выбрать конфигурацию `app`.
4. Запустить приложение на эмуляторе или устройстве с Android 8.0 и выше.

Сборка debug APK из терминала:

```powershell
.\gradlew.bat assembleDebug
```

APK после сборки:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Mock API

Внешний backend не требуется. В приложении используются такие условные endpoint-ы:

- `/apps`
- `/apps/{id}`
- `/categories`
- `/popular`

Ответы формируются в `MockBackendInterceptor`, поэтому при необходимости набор приложений можно менять прямо в мок-JSON.
